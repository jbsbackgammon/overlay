# 配信盤面作成｜使い方ガイド

日本バックギャモン協会（JBS）の大会配信で、選手名・大会名・ルール・広告などを表示するためのツールです。

**[配信盤面作成を開く](https://jbsbackgammon.github.io/overlay/)**

## 1. 配信を選ぶ

画面上部の「作業1〜3」から編集したい配信を選びます。作業ごとに別の内容を設定できます。

左側の「配信本番」を押すと、選択中の配信盤面を別ウィンドウで開きます。操作画面の下部には、現在の盤面のプレビューが表示されます。

## 2. 盤面を編集する

画面上部の入力欄から設定します。

| 項目 | 使い方 |
| --- | --- |
| 右1〜5 | 大会パネル、ガイド、ルール、広告、サムネイルなどの表示を選択します。複数枠を使う表示は連動します |
| 回次等・大会名・試合名 | 大会情報と試合を入力します。「選択」から候補を選ぶこともできます |
| 上選手・下選手 | 選手名の入力、会員からの選択、写真の設定、上下入替ができます |
| 選手映像・選手写真・英語・ガイド | チェックを付けて表示を切り替えます |
| テーマカラーなど | テーマ、大会パネル、ボード、上下選手の色を変更できます |

英語表示を有効にすると日本語名は登録された英字名と切り替わります。もともと英字の選手名はそのまま表示され、英語表記欄は編集できなくなります。

## 3. OBSで配信する

1. 操作画面で作業1〜3と表示内容を設定します。
2. 「配信本番」を押し、開いたページのURLをコピーします。
3. OBSで「ブラウザ」ソースを追加し、そのURLを入力します。
4. ブラウザソースの幅を **1920**、高さを **1080** に設定します。
5. 透明背景の盤面を、配信映像に重ねて使用します。

配信本番のURLは、変更した設定だけを圧縮することで、従来より大幅に短くしています。末尾の `?z=...` は、OBSなど別のブラウザでも同じ盤面を再現するための情報です。圧縮を利用できないブラウザでは従来の `?s=...` 形式が使われます。以前に取得した長いURLも引き続き利用できます。

基本の出力ページは次のとおりです。

| 配信 | URL |
| --- | --- |
| 作業1 | https://jbsbackgammon.github.io/overlay/output.html |
| 作業2 | https://jbsbackgammon.github.io/overlay/output.html?channel=2 |
| 作業3 | https://jbsbackgammon.github.io/overlay/output.html?channel=3 |

**OBSには「配信本番」から開いたURLを使用してください。** 上の基本URLだけを直接開いた場合、ブラウザ内に設定が保存されていなければ初期表示になります。

同じブラウザで開いた操作画面と配信本番画面は変更内容が同期されます。一方、OBSのブラウザソースは別の保存環境の場合があり、編集後の変更が自動反映されないことがあります。その場合は改めて「配信本番」からURLを開き、OBSに設定し直してください。アップロードした写真は、別のブラウザ環境では引き継がれない場合があります。

## 4. 設定を保存・再利用する

| ボタン | 使い方 |
| --- | --- |
| 設定保存 | 現在の内容を保存します。成功後はボタンに「保存完了」が2秒間表示されます |
| 設定呼出 | 以前に保存した設定を一覧から選んで呼び出します |
| JSON出力 | 現在の設定をJSONファイルに保存します |
| JSON取込 | 以前に出力したJSONファイルから設定を復元します |
| サムネ作成 | 現在の大会・選手情報を使ってサムネイル作成画面を開きます |

## よくある確認事項

- **配信本番が開かない：** ブラウザのポップアップ許可を確認してください。
- **OBSで古い盤面が表示される：** 操作画面から配信本番を開き直し、新しいURLを設定してください。
- **写真・広告が表示されない：** 画像の登録状況やブラウザ環境を確認してください。
- **盤面の一部が切れる：** OBSブラウザソースのサイズが1920×1080になっているか確認してください。

### アセットのキャッシュ更新

共通CSSは `https://jbsbackgammon.github.io/common/ui.css` を直接参照し、ソースのバージョン番号は管理しません。編集画面とOBS出力の固有CSS・JS・盤面HTML・スナップショットJSは、公開時に `scripts/stamp-assets.cjs` が実ファイルのSHA-256から同じキャッシュキーを自動付与します。検証は参照先と公開成果物の一致を確認し、手動のバージョン番号には依存しません。

試合名の選択肢は common の大会別マスタ（`JBSBrand.getMatchRounds`）から取得します。大会選択・手入力・設定呼出時にプルダウンを更新し、試合名選択時に対応する英語表記を設定します。手動編集した英語表記は、試合名をプリセットで選び直すまで保持します。

## 保守・障害時の動作

共通CSS・大会マスタ・選手処理はcommonを直接参照します。JSON取込と配信URLは許可された項目・型・値を検証します。画像の連続選択時は最後の操作を優先し、自動保存に失敗しても配信同期は継続します。その際はJSON出力で控えを保存してください。外部画像一覧の取得は10秒で打ち切り、既存の広告設定へフォールバックします。共通ファビコンはトップページの3形式を参照します。
